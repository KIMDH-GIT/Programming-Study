# Step 3-2 실습: 10진수와 2진수

이론: [3-2. 10진수와 2진수](../../../notes/03-integer-representation/3-2-decimal-binary.md)

완성 답안 소스는 제공하지 않는다. C 코드는 관찰용으로 직접 작성하고 진법 변환은 먼저 종이에서 수행한다.

## 준비

```sh
cd exercises/03-integer-representation/3-2
gcc --version
```

조건문, 반복문, 배열, 포인터, 비트 연산자와 shift를 사용하지 않는다. C17에는 표준 이진 출력 지정자가 없음을 전제로 한다.

## 필수 과제: 같은 값을 두 표기로 읽기

- **목적:** 10진수와 2진수 사이의 값 변환을 자릿값으로 설명한다.
- **작성할 파일:** `decimal_binary.c`.
- **사용할 개념:** 이진 자릿값, 2로 나눈 나머지, `unsigned int`, `U`, `%u`.

### 해야 할 일

1. `unsigned int value = 13U;`와 `int main(void)`를 사용한다.
2. 값을 `%u`로 출력한다.
3. 설명용 문자열로 `binary notation=1101`과 `place values=8+4+0+1`을 출력한다.
4. 이 문자열이 자동 이진 변환 결과가 아님을 기록한다.
5. 종이에서 `1011₂`, `1101₂`, `11111₂`를 십진수로 바꾼다.
6. 십진수 10과 25를 2로 나눈 나머지 표로 이진수로 바꾼다.

## 컴파일과 실행

```sh
gcc -std=c17 -Wall -Wextra -Wpedantic decimal_binary.c -o decimal_binary
printf 'build status=%s\n' "$?"
./decimal_binary
printf 'run status=%s\n' "$?"
```

빌드가 성공한 경우에만 실행한다. 한 번에 확인할 때는 다음처럼 연결한다.

```sh
gcc -std=c17 -Wall -Wextra -Wpedantic decimal_binary.c -o decimal_binary && ./decimal_binary
```

## 예상 관찰 결과

- 십진 출력은 13이다.
- `1101₂`의 자릿값 합도 13이다.
- 10은 `1010₂`, 25는 `11001₂`다.
- 프로그램은 객체의 원시 bit를 읽지 않는다.

## 확인 포인트

- `%u`에 `unsigned int` 값을 전달했는가?
- `1101` 문자열을 계산된 이진 출력이라고 부르지 않았는가?
- 나머지를 마지막부터 역순으로 읽었는가?
- 앞의 0과 값의 관계를 설명했는가?
- `0b`나 `%b`를 표준 C17 기능으로 사용하지 않았는가?
