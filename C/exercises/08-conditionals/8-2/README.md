# 8-2 실습: if-else
이론: [note](../../../notes/08-conditionals/8-2-if-else.md)
## 실습 목적
두 조건 경로를 구별한다.
## 작성할 파일
`if_else.c`
## 해야 할 일
0 이상/음수 메시지를 출력한다.
## 사용할 개념
`if`, `else`, 경계값.
## 컴파일 방법
```sh
gcc -std=c17 -Wall -Wextra -Wpedantic if_else.c -o if_else
```
## 실행 방법
```sh
./if_else
```
## 예상 관찰 결과
입력한 고정값에 맞는 한 문장.
## 확인 포인트
- 경로가 배타적인가?
- 0 경계를 정했는가?
## 추가 실습
- ★ 0. - ★★ 경계 변경. - ★★★ dangling else.
## 완료 기준
- [ ] 경고 없이 컴파일된다.
- [ ] 두 경로를 설명했다.
- [ ] 답안 소스를 제공하지 않았다.
