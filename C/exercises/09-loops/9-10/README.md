# 9-10 실습: 짝수 출력

이론: [note](../../../notes/09-loops/9-10-print-even-numbers.md)
## 실습 목적
변화량 2로 짝수 범위를 직접 표현한다.
## 작성할 파일
`print_even.c`
## 해야 할 일
2부터 100까지 짝수를 한 줄에 하나씩 출력한다.
## 사용할 개념
`for`, `+= 2`, 포함 경계, 짝수.
## 컴파일 방법
```sh
gcc -std=c17 -Wall -Wextra -Wpedantic print_even.c -o print_even
```
## 실행 방법
```sh
./print_even
```
## 예상 관찰 결과
2부터 100까지 50개의 짝수가 출력된다.
## 확인 포인트
첫 값 2와 마지막 값 100이 모두 포함되는가?
