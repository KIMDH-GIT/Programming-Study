# 9-8 실습: 1부터 100까지 출력

이론: [note](../../../notes/09-loops/9-8-print-1-to-100.md)
## 실습 목적
양 끝을 포함하는 100개 값의 범위를 정확히 작성한다.
## 작성할 파일
`print_1_to_100.c`
## 해야 할 일
`for`로 1부터 100까지 한 줄에 하나씩 출력한다.
## 사용할 개념
`for`, 포함 경계, 증가, `printf`.
## 컴파일 방법
```sh
gcc -std=c17 -Wall -Wextra -Wpedantic print_1_to_100.c -o print_1_to_100
```
## 실행 방법
```sh
./print_1_to_100
```
## 예상 관찰 결과
첫 줄 1, 마지막 줄 100, 총 100줄이다.
## 확인 포인트
0이나 101이 출력되지 않고 100이 포함되는가?
