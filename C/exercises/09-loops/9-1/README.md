# 9-1 실습: 반복의 초기화·조건·변화

이론: [note](../../../notes/09-loops/9-1-loop-components.md)

## 실습 목적
반복의 네 요소와 실행 순서를 값으로 추적한다.
## 작성할 파일
`loop_components.c`
## 해야 할 일
`count`를 1로 초기화하고 5 이하인 동안 출력한 뒤 1 증가시킨다. 실행 전 추적표도 작성한다.
## 사용할 개념
초기화, 조건, 본문, 변화, 0/비0 진릿값.
## 컴파일 방법
```sh
gcc -std=c17 -Wall -Wextra -Wpedantic loop_components.c -o loop_components
```
## 실행 방법
```sh
./loop_components
```
## 예상 관찰 결과
1부터 5까지 한 줄에 하나씩 출력되고 반복 종료 시 `count`는 6이다.
## 확인 포인트
조건 검사가 출력보다 먼저이며 마지막 거짓 검사도 한 번 수행되는가?
