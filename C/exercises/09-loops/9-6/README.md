# 9-6 실습: 반복 범위와 off-by-one 오류

이론: [note](../../../notes/09-loops/9-6-off-by-one.md)
## 실습 목적
경계 비교 하나가 반복 횟수에 미치는 영향을 확인한다.
## 작성할 파일
`off_by_one.c`
## 해야 할 일
`i < 5`와 `i <= 5` 반복을 각각 작성해 출력값과 검사 횟수를 표로 비교한다.
## 사용할 개념
초기값, `<`, `<=`, 종료 검사, 반열린 범위.
## 컴파일 방법
```sh
gcc -std=c17 -Wall -Wextra -Wpedantic off_by_one.c -o off_by_one
```
## 실행 방법
```sh
./off_by_one
```
## 예상 관찰 결과
첫 반복은 0~4의 5회, 둘째는 0~5의 6회 출력이다.
## 확인 포인트
마지막 참 검사와 첫 거짓 검사를 모두 기록했는가?
## 추가 실습
- ★ 1~5 - ★★ 5개 짝수 - ★★★ 감소 범위 비교
