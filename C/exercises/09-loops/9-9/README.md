# 9-9 실습: 1부터 100까지 합

이론: [note](../../../notes/09-loops/9-9-sum-1-to-100.md)
## 실습 목적
반복 누적과 안전한 초기화를 익힌다.
## 작성할 파일
`sum_1_to_100.c`
## 해야 할 일
0으로 초기화한 `sum`에 1~100을 차례로 더하고 최종값을 출력한다.
## 사용할 개념
누적 변수, `+=`, 포함 범위, signed 범위.
## 컴파일 방법
```sh
gcc -std=c17 -Wall -Wextra -Wpedantic sum_1_to_100.c -o sum_1_to_100
```
## 실행 방법
```sh
./sum_1_to_100
```
## 예상 관찰 결과
`5050`이 출력된다.
## 확인 포인트
누적 변수를 읽기 전에 0으로 초기화했는가?
## 추가 실습
- ★ 1~10 - ★★ 짝수 합 - ★★★ 역순 누적
