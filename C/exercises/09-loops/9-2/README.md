# 9-2 실습: `while`

이론: [note](../../../notes/09-loops/9-2-while.md)
## 실습 목적
선평가와 0회 실행 가능성을 확인한다.
## 작성할 파일
`while_countdown.c`
## 해야 할 일
`n = 5`에서 시작해 양수인 동안 출력하고 1 감소시킨다. 그 뒤 초기값을 0으로 바꾸어 차이를 관찰한다.
## 사용할 개념
`while`, 조건식, 감소 연산, 종료 조건.
## 컴파일 방법
```sh
gcc -std=c17 -Wall -Wextra -Wpedantic while_countdown.c -o while_countdown
```
## 실행 방법
```sh
./while_countdown
```
## 예상 관찰 결과
초기값 5에서는 5~1, 초기값 0에서는 아무 값도 출력되지 않는다.
## 확인 포인트
조건이 본문보다 먼저 평가되고 마지막 거짓 검사가 존재하는가?
## 추가 실습
- ★ 3~1 - ★★ 10~2 짝수 - ★★★ 종료 조건 오류를 실행 없이 분석
