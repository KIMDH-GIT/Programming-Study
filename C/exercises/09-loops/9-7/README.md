# 9-7 실습: 중첩 반복문

이론: [note](../../../notes/09-loops/9-7-nested-loops.md)
## 실습 목적
외부 1회마다 내부 전체가 실행되는 관계를 확인한다.
## 작성할 파일
`nested_trace.c`
## 해야 할 일
2행 3열 좌표를 순서대로 출력하고 내부 본문 실행 횟수를 계산한다.
## 사용할 개념
중첩 `for`, 외부·내부 변수, 반복 횟수.
## 컴파일 방법
```sh
gcc -std=c17 -Wall -Wextra -Wpedantic nested_trace.c -o nested_trace
```
## 실행 방법
```sh
./nested_trace
```
## 예상 관찰 결과
`(1, 1)`부터 `(2, 3)`까지 행 우선 순서로 6줄이 출력된다.
## 확인 포인트
각 행에서 column이 1로 다시 초기화되는가?
## 추가 실습
