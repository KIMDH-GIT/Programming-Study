# 9-4 실습: `for`

이론: [note](../../../notes/09-loops/9-4-for.md)
## 실습 목적
`for`의 네 요소와 평가 순서를 익힌다.
## 작성할 파일
`for_trace.c`
## 해야 할 일
`for (int i = 0; i < 5; ++i)`로 0~4를 출력하고 조건·본문·반복 식 횟수를 적는다.
## 사용할 개념
초기화 절, 조건 절, 반복 식, 본문, scope.
## 컴파일 방법
```sh
gcc -std=c17 -Wall -Wextra -Wpedantic for_trace.c -o for_trace
```
## 실행 방법
```sh
./for_trace
```
## 예상 관찰 결과
0~4가 출력되며 조건 6회, 본문과 반복 식은 각각 5회다.
## 확인 포인트
반복 식이 본문 뒤, 다음 조건 검사 전에 실행되는가?
