# Step 0-9 실습: Part 0 종합 복습

이론: [0-9 Part 0 종합 복습](../../../notes/00-compilation/0-9-part-0-review.md).

## 준비

저장소의 `C/`에서 아래 디렉터리로 이동한다. 노트의 최소 예제를 읽고 이번 디렉터리에 `hello.c`를 직접 작성한다. 0-8의 오류 실험 기록도 준비한다. 이 안내는 완성 소스나 완성된 답안 표를 제공하지 않는다.

```sh
cd exercises/00-compilation/0-9
gcc --version
```

명령, 파일 확장자, 셸 상태는 모두 **[GCC/Linux 구현]** 실습이다.

## 필수 과제

- **목적:** 소스부터 실행까지 단계와 결과를 하나의 증거 묶음으로 정리한다.
- **해야 할 일:** 전체 빌드와 단계별 빌드를 각각 수행한다. 명령마다 입력·출력 파일과 상태를 기록하고 두 실행의 출력·상태를 비교한다. 아래 오류 복습과 개념 설명도 작성한다. 끝에서 정상본의 빌드·실행을 다시 확인한다.
- **사용할 개념:** 번역 단위, 헤더, GCC 드라이버, 단계 중단 옵션, 오브젝트, 라이브러리, 심볼, 로딩, 실행 상태.
- **예상 관찰 결과:** 정상 경로에서 두 실행의 출력과 상태가 일치하고, 결함에 따라 최초 실패 단계가 다르다. 중간 파일의 내용이나 실행 파일 바이트가 같을 필요는 없다.
- **확인 포인트:** 직전 명령의 상태를 기록했는가? 실패 뒤 다음 단계를 진행하지 않았는가? 표준 규정과 구현 관찰을 표시했는가?

### A. 전체 빌드와 실행

```sh
gcc -std=c17 -Wall -Wextra -pedantic hello.c -o hello
printf 'build status=%s\n' "$?"
```

성공한 경우에만 실행한다.

```sh
./hello
printf 'run status=%s\n' "$?"
```

### B. 단계별 빌드와 실행

다음 명령을 한 줄씩 실행한다. 각 줄 **직후** `printf 'status=%s\n' "$?"`로 상태를 기록하고 성공해야 다음 줄로 넘어간다.

```sh
gcc -std=c17 -E hello.c -o hello.i
gcc -std=c17 -Wall -Wextra -pedantic -S hello.i -o hello.s
gcc -c hello.s -o hello.o
gcc hello.o -o hello-staged
./hello-staged
```

### C. 오류 복습과 설명

1. [0-8 실습 안내](../0-8/README.md)를 참고해 이번 정상본의 서로 다른 복사본에서 전처리 결함, 문법 결함, 정의 누락을 각각 재현한다. 별도 파일 이름을 사용한다.
2. 실험마다 변경 내용, 검사 명령, 첫 관련 진단, 직후 상태, 마지막 성공 단계를 기록한다. 정의 누락에서는 `-c` 성공과 링크 실패를 함께 확인한다.
3. 0-8의 제약 조건, 어셈블러, 중복 정의 실험 기록을 찾아 이번 분류표에 연결한다. 아직 없다면 해당 실습부터 수행한다.
4. 실행 요청·로딩 실패, 실행 중 실패, 논리 오류를 각 한 문장으로 구별한다. 시스템 로더나 라이브러리를 손상시켜 재현하지 않는다.
5. "헤더의 선언은 왜 외부 함수의 정의를 대신하지 못하는가?"와 "빌드 성공은 왜 정답의 증명이 아닌가?"에 답한다.
6. 정상 `hello.c`로 A의 절차를 다시 수행하여 결함 실험과 정상 결과를 분리한다.

## 추가 과제

- ★ 헤더, 오브젝트, 라이브러리, 실행 파일의 역할을 각각 한 문장으로 설명한다.
- ★★ `gcc -### hello.c -o hello`와 `gcc -### -c hello.c -o hello.o`의 실행 계획을 비교한다. 이 옵션이 실제 하위 명령을 실행하지 않는다는 점도 기록한다.
- ★★ 별도 소스 복사본의 출력만 요구와 다르게 바꾸고 정상 종료와 논리적 정답이 다름을 확인한다.

## 완료 기준

- 전체·단계별 빌드 기록과 두 실행의 출력·상태가 있다.
- 여섯 종류의 빌드 결함을 단계별로 구분한 근거가 있다.
- 실행 요청·로딩, 실행 중 실패, 논리 오류를 구별했다.
- **[C 표준]**의 논리적 번역 단계와 **[GCC/Linux 구현]**의 셸·ELF·로더·상태 관찰을 구별했다.
