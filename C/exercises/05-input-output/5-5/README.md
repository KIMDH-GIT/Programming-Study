# 5-5 실습: 주소 출력 예고

이론: [5-5 note](../../../notes/05-input-output/5-5-pointer-output-preview.md)

## 실습 목적
객체 주소를 `%p`로 안전하게 관찰한다.
## 작성할 파일
`address_preview.c`
## 해야 할 일
정수 객체 두 개의 값과 `(void *)&object`를 출력한다.
## 사용할 개념
객체, 주소 연산자, `void *`, `%p`.
## 컴파일 방법
```sh
gcc -std=c17 -Wall -Wextra -Wpedantic address_preview.c -o address_preview
```
## 실행 방법
```sh
./address_preview
```
## 예상 관찰 결과
값과 구현이 정한 주소 표현이 보인다.
## 확인 포인트
- `%p` 인자가 `void *`인가?
- 주소 형태를 일반화하지 않았는가?
## 추가 실습
- ★ **기초:** 같은 주소를 두 번 출력한다.
- ★★ **응용:** 두 객체를 비교 관찰한다.
- ★★★ **도전:** 주소 변동 이유를 기록한다.
## 완료 기준
- [ ] 경고 없이 컴파일된다.
- [ ] 주소 두 개를 관찰했다.
- [ ] 역참조를 사용하지 않았다.
- [ ] 답안 소스를 제공하지 않았다.
