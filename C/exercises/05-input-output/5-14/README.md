# 5-14 실습: 두 수의 사칙연산

이론: [5-14 note](../../../notes/05-input-output/5-14-two-number-arithmetic.md)

## 실습 목적
두 정수의 계산과 출력을 연결한다.

## 작성할 파일
`two_number_arithmetic.c`

## 해야 할 일

1. `int left = 20;`, `int right = 4;`를 선언한다.
2. 합·차·곱·몫을 각각 별도의 `int` 변수에 저장한다.
3. 네 결과 변수를 `sum`, `difference`, `product`, `quotient` label과 함께 `%d`로 출력한다.
4. `right`가 0이 아니며 이 fixture의 네 결과가 `int` 범위 안에 있음을 확인한다.
5. 출력값을 손계산한 24, 16, 80, 5와 비교한다.

## 사용할 개념
입력·처리·출력 분리, 정수식, 사칙연산, 결과 변수, `%d`, 0이 아닌 제수.

## 컴파일 방법

```sh
gcc -std=c17 -Wall -Wextra -Wpedantic -Werror two_number_arithmetic.c -o two_number_arithmetic
```

## 실행 방법

```sh
./two_number_arithmetic
```

## 예상 관찰 결과

```text
sum=24
difference=16
product=80
quotient=5
```

모든 피연산자와 결과가 `int`이므로 몫은 정수 5다. 이 fixture에서는 제수가 4이므로 0 제수 UB가 발생하지 않는다.

## 확인 포인트

- 제수가 0이 아닌가?
- 네 식의 결과를 출력 식 안에서 즉시 계산하지 않고 결과 변수에 저장했는가?
- 입력·처리·출력 세 단계를 코드에서 구별할 수 있는가?
- 정수 몫 5를 실수 5.0과 혼동하지 않았는가?
- 네 expected result가 손계산과 일치하는가?

## 추가 실습

- ★ **기초:** `left=21`, `right=4`로 바꾸고 네 결과를 실행 전에 예측한다.
- ★★ **응용:** 나머지 변수도 추가하고 21과 4에서 결과 1을 확인한다.
- ★★★ **도전:** 입력 버전에서 확인해야 할 0 제수와 정수 범위 조건을 구현 없이 설계한다.

## 완료 기준

- [ ] strict C17 옵션과 `-Werror`에서 진단 없이 compile된다.
- [ ] 네 결과를 별도 변수에 저장했다.
- [ ] 네 출력 줄이 24, 16, 80, 5와 정확히 일치한다.
- [ ] 네 결과 변수와 `%d`의 형 계약이 맞는다.
- [ ] 제수 4가 0이 아니며 fixture가 안전한 이유를 설명했다.
- [ ] 사용자 입력 버전에는 별도 검증이 필요함을 설명했다.
- [ ] 답안 소스를 제공하지 않았다.
