# 5-7 실습: `scanf`와 변수 주소

이론: [5-7 note](../../../notes/05-input-output/5-7-scanf-and-addresses.md)

## 실습 목적
입력 저장과 변수 주소, 반환값을 연결한다.
## 작성할 파일
`scanf_address.c`
## 해야 할 일
초기화한 `int`에 정수 하나를 입력하고 반환값·저장값을 출력한다.
## 사용할 개념
`scanf`, `&`, 저장 객체, 반환값.
## 컴파일 방법
```sh
gcc -std=c17 -Wall -Wextra -Wpedantic scanf_address.c -o scanf_address
```
## 실행 방법
```sh
./scanf_address
```
## 예상 관찰 결과
정상 입력에서 반환값 1과 입력값이 보인다.
## 확인 포인트
- 저장 인자에 `&`가 있는가?
- 값을 먼저 초기화했는가?
## 추가 실습
- ★ **기초:** 음수를 입력한다.
- ★★ **응용:** 문자 입력을 관찰한다.
- ★★★ **도전:** EOF를 관찰한다.
