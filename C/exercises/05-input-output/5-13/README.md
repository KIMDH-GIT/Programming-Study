# 5-13 실습: 산술 연산자 예고

이론: [5-13 note](../../../notes/05-input-output/5-13-arithmetic-operators-preview.md)

## 실습 목적
정수·실수 산술 결과를 구별한다.
## 작성할 파일
`arithmetic_preview.c`
## 해야 할 일
고정된 17과 5로 다섯 정수 연산과 실수 나눗셈을 출력한다.
## 사용할 개념
`+`, `-`, `*`, `/`, `%`, 피연산자형.
## 컴파일 방법
```sh
gcc -std=c17 -Wall -Wextra -Wpedantic arithmetic_preview.c -o arithmetic_preview
```
## 실행 방법
```sh
./arithmetic_preview
```
## 예상 관찰 결과
정수 몫 3, 나머지 2, 실수 몫 3.40이 보인다.
## 확인 포인트

- 정수·실수 결과를 구별했는가?
