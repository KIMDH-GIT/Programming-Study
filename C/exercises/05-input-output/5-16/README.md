# 5-16 실습: 섭씨·화씨 변환

이론: [5-16 note](../../../notes/05-input-output/5-16-temperature-conversion.md)

## 실습 목적
실수 비율을 사용한 단위 변환을 작성한다.
## 작성할 파일
`temperature.c`
## 해야 할 일
고정 섭씨값을 화씨로 계산해 두 값 모두 출력한다.
## 사용할 개념
`double`, `9.0 / 5.0`, `%f`.
## 컴파일 방법
```sh
gcc -std=c17 -Wall -Wextra -Wpedantic temperature.c -o temperature
```
## 실행 방법
```sh
./temperature
```
## 예상 관찰 결과
25°C가 77°F로 표시된다.
## 확인 포인트
- 정수 비율을 사용하지 않았는가?
- 단위가 표시되는가?
## 추가 실습
- ★ **기초:** 0°C를 계산한다.
- ★★ **응용:** -40°C를 확인한다.
- ★★★ **도전:** 역변환을 설계한다.
