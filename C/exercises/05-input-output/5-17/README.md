# 5-17 실습: 초를 시·분·초로 변환

이론: [5-17 note](../../../notes/05-input-output/5-17-seconds-conversion.md)

## 실습 목적
정수 몫과 나머지로 단위를 분해한다.
## 작성할 파일
`seconds_conversion.c`
## 해야 할 일
7384초에서 시·분·초를 계산해 `h:mm:ss`로 출력한다.
## 사용할 개념
정수 `/`, `%`, 중간 나머지, `%02d`.
## 컴파일 방법
```sh
gcc -std=c17 -Wall -Wextra -Wpedantic seconds_conversion.c -o seconds_conversion
```
## 실행 방법
```sh
./seconds_conversion
```
## 예상 관찰 결과
`2:03:04`가 표시된다.
## 확인 포인트
- 분에 남은 초를 사용했는가?
- 분·초가 두 자리인가?
