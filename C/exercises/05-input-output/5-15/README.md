# 5-15 실습: BMI 계산

이론: [5-15 note](../../../notes/05-input-output/5-15-bmi-calculation.md)

## 실습 목적
단위가 있는 실수 계산과 출력을 연결한다.

## 작성할 파일
`bmi.c`

## 해야 할 일

1. `double weight_kg = 68.0;`과 `double height_m = 1.75;`를 선언한다.
2. `height_m * height_m`을 분모로 사용해 BMI를 `double` 변수에 저장한다.
3. 몸무게와 키를 각각 kg, m 단위와 함께 출력한다.
4. BMI를 `BMI=%.2f` 형식으로 출력한다.
5. 키가 m 단위이며 0보다 큰지, 식이 실수 나눗셈인지 확인한다.
6. 손계산 또는 계산기로 얻은 약 22.20408과 프로그램의 둘째 자리 표시를 비교한다.

## 사용할 개념
`double`, kg·m 단위, 곱셈, 나눗셈, 양의 제수, `%.2f`, 표시 반올림.

## 컴파일 방법

```sh
gcc -std=c17 -Wall -Wextra -Wpedantic -Werror bmi.c -o bmi
```

## 실행 방법

```sh
./bmi
```

## 예상 관찰 결과

```text
weight=68.00 kg
height=1.75 m
BMI=22.20
```

수학적 계산값은 약 22.20408이며 `%.2f`가 표시를 22.20으로 반올림한다. 이 출력은 `bmi` 객체의 저장값을 22.20으로 바꾸지 않는다.

## 확인 포인트

- 키가 m 단위인가?
- 키가 0보다 큰가?
- 분모가 `height_m * height_m`인가?
- 모든 피연산자가 `double`이라 실수 나눗셈이 되는가?
- `22.20`이 단순히 “양수”인 것뿐 아니라 fixture의 식·단위와 맞는 결과인가?
- 출력 정밀도와 저장 정밀도를 구별했는가?

## 추가 실습

- ★ **기초:** `weight_kg=50.0`, `height_m=2.0`으로 바꾸고 `BMI=12.50`을 확인한다.
- ★★ **응용:** 같은 BMI를 `%.1f`, `%.4f`로 출력해 표시만 달라지는지 확인한다.
- ★★★ **도전:** 입력 버전에서 키 0, 음수, cm 입력을 어떻게 거부할지 구현 없이 검증 조건을 설계한다.

## 완료 기준

- [ ] strict C17 옵션과 `-Werror`에서 진단 없이 compile된다.
- [ ] 몸무게 68.00 kg과 키 1.75 m를 출력했다.
- [ ] BMI 식이 `weight_kg / (height_m * height_m)`와 같다.
- [ ] 출력이 `BMI=22.20`과 일치한다.
- [ ] 키 단위와 양의 제수 조건을 설명했다.
- [ ] `%.2f`가 저장값이 아니라 표시를 제어함을 설명했다.
- [ ] 답안 소스를 제공하지 않았다.
