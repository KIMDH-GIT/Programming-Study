# 5-15 실습: BMI 계산

이론: [5-15 note](../../../notes/05-input-output/5-15-bmi-calculation.md)

## 실습 목적
단위가 있는 실수 계산과 출력을 연결한다.
## 작성할 파일
`bmi.c`
## 해야 할 일
유효한 kg·m 고정값으로 BMI를 계산해 둘째 자리까지 출력한다.
## 사용할 개념
`double`, 곱셈, 나눗셈, `%.2f`.
## 컴파일 방법
```sh
gcc -std=c17 -Wall -Wextra -Wpedantic bmi.c -o bmi
```
## 실행 방법
```sh
./bmi
```
## 예상 관찰 결과
유한한 양수 BMI가 표시된다.
## 확인 포인트
- 키가 m 단위인가?
- 키가 0보다 큰가?
