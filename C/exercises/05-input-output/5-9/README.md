# 5-9 실습: 부동소수점 입력

이론: [5-9 note](../../../notes/05-input-output/5-9-floating-input-formats.md)

## 실습 목적
세 입력 서식과 포인터형을 정확히 맞춘다.
## 작성할 파일
`floating_input.c`
## 해야 할 일
세 부동소수점형에 값을 입력하고 반환값·결과를 출력한다.
## 사용할 개념
`%f`, `%lf`, `%Lf`, 객체 주소.
## 컴파일 방법
```sh
gcc -std=c17 -Wall -Wextra -Wpedantic floating_input.c -o floating_input
```
## 실행 방법
```sh
./floating_input
```
## 예상 관찰 결과
정상 입력에서 반환값 3과 세 값이 보인다.
## 확인 포인트
- 입력 서식과 주소형이 맞는가?
- 출력 규칙과 구별했는가?
## 추가 실습
- ★ **기초:** 같은 값을 입력한다.
- ★★ **응용:** 긴 소수를 비교한다.
- ★★★ **도전:** 형별 정밀도를 기록한다.
## 완료 기준
- [ ] 경고 없이 컴파일된다.
- [ ] 세 입력이 성공한다.
- [ ] 입력·출력 규칙 차이를 설명했다.
- [ ] 답안 소스를 제공하지 않았다.
