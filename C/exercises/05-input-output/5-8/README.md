# 5-8 실습: 정수 입력 서식

이론: [5-8 note](../../../notes/05-input-output/5-8-integer-input-formats.md)

## 실습 목적
세 정수 입력 서식과 저장 대상형을 맞춘다.
## 작성할 파일
`integer_input.c`
## 해야 할 일
signed 10진, unsigned 10진, 16진 값을 입력하고 반환값과 결과를 출력한다.
## 사용할 개념
`%d`, `%u`, `%x`, 객체 주소, 대입 수.
## 컴파일 방법
```sh
gcc -std=c17 -Wall -Wextra -Wpedantic integer_input.c -o integer_input
```
## 실행 방법
```sh
./integer_input
```
## 예상 관찰 결과
정상 입력에서 반환값 3과 세 값이 표시된다.
## 확인 포인트
- signed/unsigned 주소형이 맞는가?
- 모든 객체를 초기화했는가?
## 추가 실습
- ★ **기초:** `-12 12 2a`를 읽는다.
- ★★ **응용:** 중간 실패를 관찰한다.
- ★★★ **도전:** 범위 밖 입력 위험을 정리한다.
## 완료 기준
- [ ] 경고 없이 컴파일된다.
- [ ] 정상 입력에서 3을 확인했다.
- [ ] 실패 시 대입 수를 설명했다.
- [ ] 답안 소스를 제공하지 않았다.
