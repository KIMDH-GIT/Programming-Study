# 5-11 실습: `scanf` 반환값

이론: [5-11 note](../../../notes/05-input-output/5-11-scanf-return-value.md)

## 실습 목적
성공 대입 수로 입력 상태를 구별한다.
## 작성할 파일
`scanf_result.c`
## 해야 할 일
초기화한 정수 둘을 읽고 정상·부분 실패·첫 실패의 반환값을 기록한다.
## 사용할 개념
대입 수, 일치 실패, `EOF`, 초기화.
## 컴파일 방법
```sh
gcc -std=c17 -Wall -Wextra -Wpedantic scanf_result.c -o scanf_result
```
## 실행 방법
```sh
./scanf_result
```
## 예상 관찰 결과
입력에 따라 2, 1, 0 또는 `EOF`가 관찰될 수 있다.
## 확인 포인트
- 결과 객체를 초기화했는가?
- 반환값과 입력값을 구별했는가?
## 추가 실습
- ★ **기초:** 정상 입력을 기록한다.
- ★★ **응용:** 부분 실패를 만든다.
- ★★★ **도전:** EOF를 관찰한다.
