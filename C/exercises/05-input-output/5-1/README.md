# 5-1 실습: `printf` 인자 대응

이론: [5-1 note](../../../notes/05-input-output/5-1-printf-format-arguments.md)

## 실습 목적
서식 문자열과 인자의 개수·순서·형을 맞춘다.
## 작성할 파일
`printf_arguments.c`
## 해야 할 일
이름 문자열, 나이 `int`, 진도율 `double`을 출력하고 첫 호출의 반환값도 출력한다.
## 사용할 개념
`printf`, 서식 문자열, 인자, 반환값, `%%`.
## 컴파일 방법
```sh
gcc -std=c17 -Wall -Wextra -Wpedantic printf_arguments.c -o printf_arguments
```
## 실행 방법
```sh
./printf_arguments
```
## 예상 관찰 결과
세 값과 출력 문자 수가 표시된다.
## 확인 포인트
- 변환 지정과 인자 순서가 맞는가?
- 줄바꿈도 문자 수에 포함했는가?
## 추가 실습
- ★ **기초:** `%%`를 한 번 출력한다.
- ★★ **응용:** 두 호출의 반환값을 비교한다.
- ★★★ **도전:** 잘못된 대응 예를 실행하지 않고 분석한다.
