# 5-1 실습: `printf` 인자 대응

이론: [5-1 note](../../../notes/05-input-output/5-1-printf-format-arguments.md)

## 실습 목적
서식 문자열과 인자의 개수·순서·형을 맞춘다.

## 작성할 파일
`printf_arguments.c`

## 해야 할 일

1. 이름은 `"Kim"`, 나이는 `20`, 진도율은 `75.0`으로 준비한다.
2. 첫 `printf` 호출에서 세 값을 다음 형식으로 출력한다.

   ```text
   name=Kim age=20 progress=75.0%
   ```

3. `%` 문자는 `%%`로 출력한다.
4. 첫 호출의 반환값을 `int` 변수에 저장한다.
5. 두 번째 호출에서 `written=31` 형식으로 반환값을 출력한다.
6. 줄바꿈을 포함해 첫 호출이 31문자를 쓴 이유를 직접 세어 기록한다.

## 사용할 개념
`printf`, 서식 문자열, 인자, 반환값, `%%`.

## 컴파일 방법

```sh
gcc -std=c17 -Wall -Wextra -Wpedantic -Werror printf_arguments.c -o printf_arguments
```

## 실행 방법

```sh
./printf_arguments
```

## 예상 관찰 결과

```text
name=Kim age=20 progress=75.0%
written=31
```

첫 줄의 문자 수 31에는 마지막 줄바꿈 문자 1개도 포함된다. `%%`는 출력 문자 `%` 하나를 만들지만 추가 인자는 소비하지 않는다.

## 확인 포인트

- 변환 지정과 인자 순서가 맞는가?
- 이름·나이·진도율이 각각 `%s`, `%d`, `%.1f`와 대응하는가?
- `%`를 출력하기 위해 `%%`를 사용했는가?
- 공백, `%`, 줄바꿈을 모두 포함해 31문자를 설명할 수 있는가?

## 추가 실습

- ★ **기초:** 일반 문자만 출력하는 호출의 반환값을 실행 전에 예측한다.
- ★★ **응용:** 첫 줄 끝의 `%%`를 두 번으로 늘리고 반환값 변화를 예측한 뒤 확인한다.
- ★★★ **도전:** 잘못된 대응 예를 실행하지 않고 분석한다.
