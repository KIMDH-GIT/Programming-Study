# 4-6 실습: 32-bit 레지스터 값 모델

이론: [4-6. `uint32_t register_value`와 레지스터 모델](../../../notes/04-fixed-width-integers/4-6-register-value-model.md)

## 실습 목적

실제 장치 접근 없이 32-bit 레지스터 값을 모델링하고 고정된 8자리 16진 표기로 관찰한다.

## 작성할 파일

`register_model.c`

## 해야 할 일

1. `<inttypes.h>`와 `<stdio.h>`를 포함한다.
2. reset 값 `0x00000000`과 예시 값 `0xA5A50001`을 `uint32_t`로 선언한다.
3. 두 초기값에 `UINT32_C`를 사용한다.
4. `0x%08`과 `PRIx32`를 조합해 출력한다.
5. `UINT32_MAX`를 `PRIu32`로 출력한다.
6. “이 코드는 실제 장치 레지스터에 접근하지 않는다”라고 결과표에 쓴다.

## 사용할 개념

32-bit unsigned 값, 16진 네 bit 묶음, integer constant macro, `PRI` 출력 매크로, 값 모델과 장치 접근의 구분.

## 컴파일 방법

```sh
gcc -std=c17 -Wall -Wextra -Wpedantic register_model.c -o register_model
```

## 실행 방법

```sh
./register_model
```

## 예상 관찰 결과

reset 값은 `0x00000000`, 예시 값은 `0xa5a50001`로 출력된다. 최댓값은 10진수로 표시된다.

## 확인 포인트

- 두 변수가 평범한 자동 객체임을 설명했는가?
- 32 bit와 8자리 16진수의 관계를 적었는가?
- `PRIx32` 앞에 `%08`을 올바르게 결합했는가?
- 출력 문자 순서를 endianness 증거로 오해하지 않았는가?
- pointer, `volatile`, bit 연산을 추가하지 않았는가?

## 추가 실습

- ★ **기초:** `0x12345678`을 8개의 16진 숫자와 32 bit로 연결한다.
- ★★ **응용:** `0x0000002A`를 16진과 10진으로 출력한다.
- ★★★ **도전:** 값 폭과 실제 접근 계약의 차이를 세 항목으로 정리한다.
