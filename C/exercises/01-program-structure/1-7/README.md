# Step 1-7 실습: 주석·들여쓰기·자기소개

이론: [1-7 주석·들여쓰기·자기소개 실습](../../../notes/01-program-structure/1-7-comments-indentation-profile.md).

## 준비

이 디렉터리에서 학습자가 직접 작성할 파일 이름은 **`profile.c`**다. 완성 소스는 제공하지 않는다.

이식성 비교에는 ASCII 문구를 사용한다. 한글 문구를 직접 쓰면 컴파일러의 문자 집합·인코딩과 터미널 표시 지원에 의존한다는 점을 기록한다.

**[GNU/Linux 구현]** 저장소의 `C/`에서 시작했다면 다음처럼 이동하고, 편집기로 `profile.c`를 직접 작성한다.

```sh
cd exercises/01-program-structure/1-7
gcc -std=c17 -Wall -Wextra -pedantic profile.c -o profile
./profile
printf 'run status=%s\n' "$?"
```

빌드가 실패했다면 `./profile`을 실행하지 않는다. 이전 실행 파일이 남아 있을 수 있으므로 빌드 성공과 실행 결과를 구분한다.

## 필수 과제

- **목적:** 주석과 일관된 들여쓰기를 사용해 Part 1 지식으로 읽기 쉬운 자기소개 프로그램을 작성한다.
- **해야 할 일:** `profile.c`에 `<stdio.h>`, `int main(void)`, 중괄호, `printf` 문장, `return 0;`을 직접 작성한다. 이름, 좋아하는 것 또는 관심 분야, C를 배우는 이유를 각각 한 줄로 출력한다. 실제 내용에 맞춰 `\t`, `\"`, `\\` 중 하나 이상을 사용한다. `//` 주석과 `/* ... */` 주석을 각각 하나 이상 쓰고 함수 본문은 한 가지 들여쓰기 규칙으로 정렬한다.
- **사용할 개념:** 표준 헤더, 프로그램 시작 함수, statement·중괄호·세미콜론, 문자열 리터럴, `printf`, `\n`·`\t`·`\"`·`\\`, 주석, 들여쓰기, `return 0;`.
- **예상 관찰 결과:** 작성한 세 항목 이상이 정한 순서대로 줄 단위로 출력되고 주석은 화면에 나타나지 않는다. 정상 실행은 성공 상태로 끝난다. 탭의 표시 폭은 환경마다 다를 수 있다.
- **확인 포인트:** 모든 `printf` 문장에 세미콜론이 있는가? `/*`와 `*/`가 짝인가? 문자열 속 `//` 또는 `/*`를 주석으로 착각하지 않았는가? 들여쓰기뿐 아니라 중괄호도 확인했는가? 출력과 종료 상태를 따로 기록했는가?

## 추가 과제

- ★ 별도 파일에서 `"// 주석 아님"`과 `"/* 주석 아님 */"`을 출력하고, 기호가 화면에 보이는 이유를 노트의 번역 단계 3과 연결해 적는다.
- ★★ `profile.c` 복사본의 들여쓰기만 흐트러뜨려도 출력이 바뀌지 않음을 확인한 뒤 다시 한 규칙으로 정렬한다. 중괄호와 세미콜론은 삭제하지 않는다.

## 완료 기준

- 학습자가 작성한 `profile.c`가 경고 옵션과 함께 빌드된다.
- 자기소개 항목 세 줄 이상, 두 종류의 주석, 일관된 들여쓰기, 필요한 이스케이프 시퀀스가 있다.
- 주석은 출력되지 않고, 출력 내용과 실행 상태를 각각 확인했다.
