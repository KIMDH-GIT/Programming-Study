# Step 1-5 실습: 이스케이프 시퀀스

이론: [1-5 이스케이프 시퀀스](../../../notes/01-program-structure/1-5-escape-sequences.md)

완성 소스는 제공하지 않는다. 이 디렉터리에 학습자 본인이 `escape_sequences.c`를 작성한다.

## 준비

`C/` 디렉터리에서 시작한다.

```sh
cd exercises/01-program-structure/1-5
gcc --version
```

이후 명령은 이 실습 디렉터리에서 실행한다. 명령과 셸 관찰은 GCC/Linux 환경용이다.

## 필수 실습: 특수 문자가 있는 한 줄 만들기

- **목적:** `\n`, `\t`, `\"`, `\\`를 문자열 리터럴 안에서 구별해 사용한다.
- **해야 할 일:** `escape_sequences.c`에 `puts`를 호출하는 C17 프로그램을 직접 작성한다. 한 문자열 리터럴에 네 이스케이프 시퀀스를 각각 한 번 이상 넣고, 문자열 내용에는 자신이 정한 ASCII 단어를 사용한다. 빌드·실행한 뒤 소스 표기와 화면 관찰을 기록한다.
- **사용할 개념:** 문자열 리터럴, `\n`, `\t`, `\"`, `\\`, `puts`, 표준 출력.
- **예상 관찰 결과:** 새 줄, 탭처럼 보이는 구분, 큰따옴표, 역슬래시가 출력에 나타난다. 탭의 정확한 표시 폭은 터미널이나 출력 장치에 따라 다를 수 있다.
- **확인 포인트:** `"\n"`과 `"\\n"`을 구별했는가? 내부 큰따옴표에 `\"`를 썼는가? 역슬래시에 `\\`를 썼는가? 탭 폭을 고정 숫자로 가정하지 않았는가?

```sh
gcc -std=c17 -Wall -Wextra -pedantic escape_sequences.c -o escape_sequences
./escape_sequences
printf 'status=%s\n' "$?"
```

실행 직후에만 `$?`를 읽는다. `printf` 실행 뒤 다시 읽으면 `printf`의 상태가 된다.

## 기록할 내용

| 소스 표기 | 내가 의도한 문자열 내용 | 실제 관찰 | 환경에 고정되지 않는 부분 |
|---|---|---|---|
| `\n` | | | |
| `\t` | | | |
| `\"` | | | |
| `\\` | | | |

`\n`을 특정 물리 바이트 수 또는 모든 터미널의 동일한 줄 이동으로 설명하지 않는다. `\t`의 표시 간격도 출력 장치마다 달라질 수 있다.

## 추가 실습

- ★ `"A\nB"`와 `"A\\nB"`를 별도 출력으로 비교하고 차이를 기록한다.
- ★ `\"`와 `\\`를 포함한 문구를 자신이 직접 만든다.
- ★★ 표준 출력을 파일로 리다이렉션하고 터미널 표시와 파일의 내용을 구별해 기록한다. 특정 파일 형식을 C 표준의 요구라고 쓰지 않는다.
