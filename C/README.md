# C Study

## Purpose

C 문법부터 메모리, 컴파일러, CPU, 운영체제, 시스템 프로그래밍까지 단계적으로 학습하고 기록하는 디렉토리다.

## Learning Method

- 기간을 정하지 않고 개념의 선후관계에 따라 학습한다.
- 원하는 Step만 선택해 이론을 정리하고 코드를 직접 작성한다.
- 실습 결과와 프로젝트를 Git으로 기록한다.

전체 학습 과정: [C_CURRICULUM.md](./C_CURRICULUM.md)

