# 8-1. `if`
`if`는 조건식이 0이 아닐 때 controlled statement를 실행한다.
## 1. 학습 목표
- 조건식과 controlled statement를 구별한다.
- 0/비0 진릿값을 설명한다.
- compound statement를 사용한다.
## 2. 선수 지식
Part 7의 비교·논리 연산을 사용한다.
## 3. 핵심 개념
C17에서 0은 거짓, 0이 아닌 값은 참이다. 중괄호는 statement 하나에는 문법상 필수가 아니지만 일관되게 사용하면 실수를 줄인다.
## 4. 문법
```c
if (condition) { statement; }
```
## 5. 최소 코드 예제
```c
#include <stdio.h>
int main(void){int value=7;if(value>0){printf("positive\n");}return 0;}
```
## 6. 코드 해석
비교 결과 1이므로 compound statement가 실행된다.
## 7. 내부 동작
컴파일러는 분기 또는 동등한 형태로 번역할 수 있으며 CPU 명령 하나를 보장하지 않는다.
## 8. 자주 하는 실수
- 조건 결과를 별도 bool형이라고 단정한다.
- 중괄호 들여쓰기만 믿는다.
- `if(x=5)`를 syntax error라고 부른다.
## 9. 필수 실습
양수 조건에서 한 문장을 출력한다. [실습 README](../../exercises/08-conditionals/8-1/README.md).
## 10. 추가 실습
- ★ 0 조건. - ★★ 비0 조건. - ★★★ 대입 조건 분석.
## 11. 확인 문제
1. 거짓 값은? 2. controlled statement란? 3. 중괄호는 항상 필수인가? 4. 비교 결과형은?
## 12. 핵심 정리
`if`는 조건식의 0/비0 결과로 statement 실행 여부를 정한다.
