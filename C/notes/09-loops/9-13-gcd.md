# 9-13. 실습: 최대공약수

유클리드 알고리즘은 나머지가 0이 될 때까지 두 값을 갱신해 최대공약수를 구한다.

## 1. 학습 목표
- 종료 횟수가 미리 정해지지 않은 `while`을 사용한다.
- 나머지 계산 전 제수가 0이 아님을 보장한다.
- 두 상태를 임시 변수로 안전하게 갱신한다.

## 2. 선수 지식
Part 7의 `%`, Step 9-2의 `while`, 0으로 나누기의 undefined behavior를 안다.

## 3. 핵심 개념
양의 정수 `a`, `b`에서 `gcd(a, b) == gcd(b, a % b)`다. `b != 0`인 동안 나머지를 구하고 `a = b`, `b = remainder`로 바꾼다. 종료 시 `a`가 최대공약수다. 조건이 `%`보다 먼저 0을 차단한다.

## 4. 문법
```c
while (b != 0) {
    int remainder = a % b;
    a = b;
    b = remainder;
}
```

## 5. 최소 코드 예제
```c
#include <stdio.h>

int main(void)
{
    int a = 48;
    int b = 18;
    while (b != 0) {
        int remainder = a % b;
        a = b;
        b = remainder;
    }
    printf("%d\n", a);
    return 0;
}
```

## 6. 코드 해석
상태는 `(48,18) → (18,12) → (12,6) → (6,0)`으로 변한다. `b == 0`에서 `%`를 평가하지 않고 종료하며 6을 출력한다.

## 7. 내부 동작
[C17 표준] 두 번째 피연산자가 0인 `%`는 undefined behavior다. 조건 `b != 0`이 신뢰 경계를 만든다. 두 대입 사이에 나머지를 보존할 임시 변수가 없으면 필요한 이전 값이 사라진다.

## 8. 자주 하는 실수
- `a % b`를 계산한 뒤 0인지 검사한다.
- `a = b` 후에 `a % b`를 계산해 이전 `a`를 잃는다.
- 양수가 아닌 입력까지 설명 없이 일반화한다.
- 종료 조건을 `remainder != 0`으로 두면서 초기화하지 않는다.
