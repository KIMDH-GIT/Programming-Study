# 9-2. `while`

`while`은 본문을 실행하기 전에 조건을 평가하는 선평가 반복문이다.

## 1. 학습 목표
- `while`의 평가 순서를 설명한다.
- 본문이 0번 실행되는 경우를 판단한다.
- 종료 조건을 향해 상태를 변화시킨다.

## 2. 선수 지식
Step 9-1의 초기화·조건·변화와 Part 8의 조건식 규칙이 필요하다.

## 3. 핵심 개념
`while`은 조건을 먼저 평가한다. 결과가 0이면 곧바로 반복 뒤로 이동하므로 본문이 한 번도 실행되지 않을 수 있다. 0이 아니면 본문 전체를 실행한 뒤 다시 조건으로 돌아간다. 반복 횟수를 미리 알기 어렵고 특정 상태까지 계속해야 할 때 자연스럽다.

## 4. 문법
```c
while (condition) {
    statement;
}
```

## 5. 최소 코드 예제
```c
#include <stdio.h>

int main(void)
{
    int n = 3;
    while (n > 0) {
        printf("%d\n", n);
        --n;
    }
    return 0;
}
```

## 6. 코드 해석
검사 순서는 `3 > 0`, `2 > 0`, `1 > 0`, `0 > 0`이다. 앞의 세 검사 뒤에는 출력과 감소가 실행되며 마지막 검사는 거짓이므로 본문에 들어가지 않는다. 초기값이 0이었다면 출력은 0회다.

## 7. 내부 동작
[C 언어 관점] 조건식은 각 반복 전에 full expression으로 평가된다. 본문을 마치면 제어가 조건 검사로 돌아간다. 조건 안의 대입도 유효한 식이지만 `while (n = 5)`는 매번 5를 대입하고 참이 되므로 보통 오류이며 GCC의 `-Wall`이 경고할 수 있다.

## 8. 자주 하는 실수
- `while`이 최소 한 번 실행된다고 생각한다.
- `--n`을 빼서 `n > 0`이 계속 참이 되게 한다.
- 중괄호 없이 여러 줄이 모두 반복된다고 생각한다.
- `while (1)`을 signed 증가 변수와 결합해 그 변수가 영원히 안전하다고 설명한다.

## 12. 핵심 정리
`while`은 선평가하므로 0회 실행이 가능하며, 본문은 조건을 종료 방향으로 바꾸어야 한다.
