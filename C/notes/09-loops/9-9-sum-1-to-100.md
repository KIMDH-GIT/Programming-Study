# 9-9. 실습: 1부터 100까지 합

누적 변수는 이전 반복까지의 결과를 보존하고 현재 값을 더해 전체 결과를 만든다.

## 1. 학습 목표
- 누적값을 올바른 항등값으로 초기화한다.
- 반복 범위와 합의 자료형 범위를 검토한다.
- 반복 불변식의 기초를 말로 설명한다.

## 2. 선수 지식
Step 9-8의 1~100 범위와 Part 7의 `+=`를 사용한다.

## 3. 핵심 개념
덧셈 누적의 시작값은 0이다. 각 반복 직후 `sum`은 1부터 현재 `number`까지의 합이다. 1~100의 합 5050은 `int`가 최소 보장하는 범위 안이지만, 더 큰 범위에서는 더하기 전에 자료형의 표현 가능 범위를 검토해야 한다.

## 4. 문법
```c
int sum = 0;
for (int number = 1; number <= 100; ++number) {
    sum += number;
}
```

## 5. 최소 코드 예제
```c
#include <stdio.h>

int main(void)
{
    int sum = 0;
    for (int number = 1; number <= 100; ++number) {
        sum += number;
    }
    printf("%d\n", sum);
    return 0;
}
```

## 6. 코드 해석
첫 반복 뒤 합은 1, 둘째 뒤 3, 셋째 뒤 6이다. 같은 규칙이 100까지 이어져 5050이 된다. 출력은 반복이 모두 끝난 뒤 한 번 수행한다.

## 7. 내부 동작
[C17 표준] 표현 가능한 signed 범위를 넘는 덧셈은 undefined behavior다. 이 예제의 값은 안전하다. 수학 공식으로 바꾸는 최적화 여부는 구현에 달렸으며 소스가 특정 최적화를 요구하지 않는다.

## 8. 자주 하는 실수
- `sum`을 초기화하지 않고 읽는다.
- 본문에서 `sum = number`로 이전 합을 덮어쓴다.
- 0~100 또는 1~99를 더한다.
- 매우 큰 상한에서도 `int`가 항상 충분하다고 가정한다.
