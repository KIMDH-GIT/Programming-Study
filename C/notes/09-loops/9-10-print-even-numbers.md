# 9-10. 실습: 짝수 출력

짝수 출력은 조건으로 고르는 방식과 변화량 자체를 2로 만드는 방식으로 구현할 수 있다.

## 1. 학습 목표
- `% 2` 판별과 2씩 증가하는 반복을 비교한다.
- 범위 안의 첫 짝수와 마지막 짝수를 정한다.
- 불필요한 검사를 줄이되 읽기 쉬운 흐름을 선택한다.

## 2. 선수 지식
Part 7의 나머지 연산과 Step 9-6의 범위 설계를 사용한다.

## 3. 핵심 개념
`number % 2 == 0`은 정수가 2로 나누어떨어지는지 검사한다. 범위의 시작이 2이고 짝수만 필요하다면 `number += 2`가 의도를 직접 표현한다. 두 방식 모두 정의된 동작이며 요구 사항에 맞는 시작값과 끝 조건이 핵심이다.

## 4. 문법
```c
for (int number = 2; number <= 100; number += 2) {
    printf("%d\n", number);
}
```

## 5. 최소 코드 예제
```c
#include <stdio.h>

int main(void)
{
    for (int number = 2; number <= 10; number += 2) {
        printf("%d\n", number);
    }
    return 0;
}
```

## 6. 코드 해석
2, 4, 6, 8, 10을 출력한다. 10을 출력한 뒤 12가 되고 `12 <= 10`이 거짓이다. 본문은 5회 실행된다.

## 7. 내부 동작
[C 언어 관점] `number += 2`는 현재 값을 읽어 2를 더한 뒤 저장하는 side effect다. 이 예제의 값은 `int` 범위 안이다. 조건과 변화는 각각 별도의 full expression이므로 같은 객체를 한 식에서 중복 변경하는 문제도 없다.

## 8. 자주 하는 실수
- 0을 포함할지 요구를 확인하지 않는다.
- 1에서 시작해 2씩 증가하면서 짝수가 나온다고 생각한다.
- `< 100`으로 100을 누락한다.
- 반복 식에 불필요하게 복잡한 side effect를 넣는다.

1. 예제는 몇 번 실행되는가?
2. 0은 짝수인가?
3. 1에서 2씩 증가하면 어떤 값들이 나오는가?
4. 100을 포함하려면 어떤 조건을 쓰는가?

## 12. 핵심 정리
짝수 범위는 첫 값과 끝 포함 여부를 정하고 2씩 변화시키면 간단히 표현할 수 있다.
