# 9-8. 실습: 1부터 100까지 출력

경계가 포함된 연속 정수 출력을 통해 초기값·조건·변화를 결합한다.

## 1. 학습 목표
- 1과 100을 모두 포함하는 범위를 작성한다.
- 첫 값·마지막 값·종료 후 값을 구분한다.
- 출력 횟수를 계산한다.

## 2. 선수 지식
Step 9-4의 `for`와 Step 9-6의 off-by-one 검증이 필요하다.

## 3. 핵심 개념
1부터 100까지는 닫힌 범위 `[1, 100]`이다. 초기값 1, 조건 `number <= 100`, 변화 `++number`로 표현하면 본문은 100회 실행되고 종료 검사는 `number == 101`에서 거짓이 된다.

## 4. 문법
```c
for (int number = 1; number <= 100; ++number) {
    printf("%d\n", number);
}
```

## 5. 최소 코드 예제
```c
#include <stdio.h>

int main(void)
{
    for (int number = 1; number <= 100; ++number) {
        printf("%d\n", number);
    }
    return 0;
}
```

## 6. 코드 해석
첫 검사 `1 <= 100`과 마지막 참 검사 `100 <= 100` 뒤에 출력한다. 증가 후 101이 되고 `101 <= 100`이 거짓이라 종료한다. 출력 100회, 조건 검사 101회다.

## 7. 내부 동작
[C 언어 관점] 각 `printf` 호출은 순서대로 newline을 포함한 출력을 만든다. [GNU/Linux 환경] 터미널과 파일로 보낼 때 buffering 방식은 달라질 수 있지만 C 코드의 호출 순서는 같다.

## 8. 자주 하는 실수
- 0에서 시작해 0~100을 101개 출력한다.
- `< 100`으로 100을 누락한다.
- 반복 횟수와 조건 검사 횟수를 혼동한다.
- 한 줄 출력을 요구하면서 `\n`을 빼먹는다.

## 9. 필수 실습

## 11. 확인 문제
1. 본문은 몇 번 실행되는가?
2. 마지막 거짓 검사 때 값은?
3. 조건을 `< 100`으로 바꾸면 마지막 출력은?
4. 100부터 1까지 감소할 때 조건은?

## 12. 핵심 정리
