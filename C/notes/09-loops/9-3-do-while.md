# 9-3. `do-while`

`do-while`은 본문을 먼저 실행하고 조건을 평가하는 후평가 반복문이다.

## 1. 학습 목표
- `do-while`의 후평가 순서를 설명한다.
- 최소 1회 실행을 `while`과 비교한다.
- 닫는 괄호 뒤 세미콜론을 정확히 쓴다.

## 2. 선수 지식
Step 9-2의 선평가 `while`과 0/비0 조건 규칙을 안다.

## 3. 핵심 개념
제어가 `do`에 도달하면 본문을 먼저 한 번 실행한다. 그 뒤 조건이 0이 아니면 다시 본문으로 돌아가고 0이면 끝난다. 따라서 메뉴를 적어도 한 번 보여 주는 등 첫 실행이 반드시 필요한 흐름에 맞는다. 단지 “한 번 실행하고 싶다”는 이유만으로 선택하지 말고 반복의 의미와 종료 조건을 함께 본다.

## 4. 문법
```c
do {
    statement;
} while (condition);
```
마지막 `;`는 문법의 일부다.

## 5. 최소 코드 예제
```c
#include <stdio.h>

int main(void)
{
    int n = 0;
    do {
        printf("%d\n", n);
        ++n;
    } while (n < 3);
    return 0;
}
```

## 6. 코드 해석
처음에는 조건 검사 없이 0을 출력하고 `n`을 1로 만든다. 이후 1과 2도 출력한다. `n`이 3이 된 뒤 조건이 거짓이어서 종료한다. 초기값이 3이어도 3은 한 번 출력된다.

## 7. 내부 동작
[C 언어 관점] 각 반복에서 본문 뒤에 조건 full expression이 평가된다. `continue`를 만나도 곧바로 본문 시작이 아니라 조건 검사로 이동한다. 컴파일러는 결과가 같다면 `while`과 유사한 분기 구조로 번역할 수 있다.

## 8. 자주 하는 실수
- `while (condition)` 뒤의 세미콜론을 빠뜨린다.
- 조건을 먼저 검사한다고 잘못 추적한다.
- 최소 1회 실행이 부적절한 입력 처리에도 무조건 사용한다.
- 변화가 없어 조건이 계속 참이 된다.

## 12. 핵심 정리
`do-while`은 본문 후 조건을 검사해 최소 한 번 실행되며, 문법 끝에 세미콜론이 필요하다.
