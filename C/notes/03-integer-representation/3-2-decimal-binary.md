# Step 3-2. 10진수와 2진수

기준은 C17 호스트 환경이다. 같은 정수 값을 10진 표기와 2진 표기로 오가며, 숫자의 표기와 C 객체의 표현을 구별한다.

## 1. 학습 목표

- 10진수와 2진수의 자릿값을 비교한다.
- 이진수를 자릿값의 합으로 계산해 십진수로 바꾼다.
- 십진수를 2로 나눈 나머지로 이진수로 바꾼다.
- 앞의 0이 값에 영향을 주지 않음을 설명한다.
- 이진 표기, C 정수 값, 실제 객체 표현을 구별한다.

## 2. 선수 지식

[3-1. bit·byte와 자릿값](3-1-bit-byte-place-value.md)의 bit와 `2`의 거듭제곱을 사용한다. C 코드에서는 `unsigned int`, `printf`, `%u`만 사용하며 반복문과 배열은 아직 쓰지 않는다.

## 3. 핵심 개념

10진수는 오른쪽부터 `10⁰`, `10¹`, `10²`의 자릿값을 갖고, 2진수는 `2⁰`, `2¹`, `2²`의 자릿값을 갖는다.

```text
13₁₀ = 1×10¹ + 3×10⁰
1101₂ = 1×2³ + 1×2² + 0×2¹ + 1×2⁰
       = 8 + 4 + 0 + 1
       = 13₁₀
```

### 이진수에서 십진수로

오른쪽부터 자릿값 `1, 2, 4, 8, 16, ...`을 적고 bit가 1인 자리만 더한다. `00001101₂`와 `1101₂`는 같은 값 13이다. 앞의 0은 자릿수를 맞추는 표기일 뿐 값을 늘리지 않는다.

### 십진수에서 이진수로

양의 십진수를 2로 계속 나누고 나머지를 아래에서 위로 읽는다.

```text
13 ÷ 2 = 6 ... 1
 6 ÷ 2 = 3 ... 0
 3 ÷ 2 = 1 ... 1
 1 ÷ 2 = 0 ... 1

13₁₀ = 1101₂
```

0의 이진 표기는 `0₂`다. 이 절차는 종이 계산법이며 아직 C 반복문으로 구현하지 않는다.

### 값과 표기, 객체 표현

정수 13은 하나의 수학적 값이다. `13₁₀`과 `1101₂`는 같은 값을 나타내는 서로 다른 표기다. C17 소스에서 접두사 없는 `1101`은 이진수가 아니라 십진 정수 상수 1101이다. `0b1101`은 표준 C17 정수 리터럴이 아니다.

**[C 표준]** 정수형 객체는 순수 이진 표기법을 이용해 값을 나타내지만, padding과 signed 표현 등 구현 규칙이 있다. 종이에 쓴 이진 숫자를 곧바로 메모리 byte 배열이라고 부르지 않는다.

## 4. 문법

C17 `printf`에는 정수를 2진수로 출력하는 표준 변환 지정자가 없다.

```c
unsigned int value = 13U;
printf("%u\n", value);
printf("binary notation: 1101\n");
```

둘째 줄의 `1101`은 계산된 결과가 아니라 설명용 문자열이다. `%b`를 이식 가능한 C17 서식이라고 사용하지 않는다. 실제 이진 변환 프로그램은 반복문을 배운 뒤 작성할 수 있다.

## 5. 최소 코드 예제

`decimal_binary.c`에 저장한다.

```c
#include <stdio.h>

int main(void)
{
    unsigned int value = 13U;

    printf("decimal=%u\n", value);
    printf("binary notation=1101\n");
    printf("place values=8+4+0+1\n");
    return 0;
}
```

```sh
gcc -std=c17 -Wall -Wextra -Wpedantic decimal_binary.c -o decimal_binary && ./decimal_binary
```

출력 문자열은 계산 답을 보여 주는 학습 표식이다. 프로그램이 `value`의 실제 bit를 검사한 것은 아니다.

## 6. 코드 해석

- `13U`는 값 13의 unsigned 정수 상수다.
- `%u`는 `unsigned int` 값을 십진수로 출력한다.
- `1101` 문자열은 같은 값의 이진 표기를 사람이 기록한 것이다.
- 세 번째 줄은 각 이진 자리의 값을 합한 식이다.
- `return 0;`은 성공 종료를 나타낸다.

## 7. 내부 동작

1. **[C 표준]** 컴파일러는 `13U`를 `unsigned int` 값으로 해석한다.
2. **[표준 라이브러리]** `%u`는 그 값을 십진 문자로 변환한다. 객체의 원시 bit를 그대로 출력하지 않는다.
3. **[구현]** 대상은 `unsigned int`의 크기와 padding을 정한다. 값 13은 모든 C17 `unsigned int`에 표현 가능하다.
4. **[CPU]** 정수 계산은 보통 이진 회로로 구현되지만, C는 특정 레지스터 폭이나 명령을 요구하지 않는다.
5. **[메모리]** `1101₂`라는 자릿값 그림만으로 객체의 byte 배치나 주소를 알 수 없다.

## 8. 자주 하는 실수

- `1101`을 C 코드에서 이진수 13이라고 생각한다.
- `0b1101`을 표준 C17 문법이라고 한다.
- C17 `printf`에 표준 `%b`가 있다고 생각한다.
- 나머지를 위에서 아래로 읽어 결과를 뒤집는다.
- 앞의 0이 다른 값을 만든다고 생각한다.
- 종이의 bit 열을 실제 메모리 관찰 결과라고 부른다.

## 12. 핵심 정리

- 2진수의 자릿값은 오른쪽부터 1, 2, 4, 8 순서다.
- 이진수는 자릿값을 더해 십진수로 바꾼다.
- 십진수는 2로 나눈 나머지를 역순으로 읽어 이진수로 바꿀 수 있다.
- 값, 숫자 표기, C 객체 표현은 같은 개념이 아니다.
- C17에는 `0b` 정수 리터럴과 표준 `%b` 출력이 없다.
