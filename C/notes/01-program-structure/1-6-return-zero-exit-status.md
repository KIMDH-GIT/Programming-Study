# Step 1-6. `return 0`과 종료 상태

기준: C17, 호스트 환경(hosted environment). 이 Step에서는 초기 `main` 함수가 반환하는 값과 프로그램 종료 상태를 구별해 이해한다.

## 1. 학습 목표

- 초기 `main`의 `return 표현식;`이 반환 값을 계산한다는 점을 설명한다.
- `return 0;`이 성공 종료를 나타냄을 안다.
- 초기 `main`에서 `return 값;`이 `exit(값)`을 호출하는 것과 동등함을 설명한다.
- C99 이후 초기 `main`의 끝 `}`에 도달하는 것이 `return 0;`과 동등함을 안다.
- 셸에 보이는 종료 상태의 표현은 환경별 관찰임을 구별한다.

## 2. 선수 지식

- `int main(void)`와 함수 본문 `{ ... }`의 기본 구조를 안다.
- 정수 리터럴 `0`과 `return` 문을 본 적이 있다.
- 터미널에서 프로그램 실행 뒤 직전 명령의 상태를 확인할 수 있다.

## 3. 핵심 개념

호스트 환경에서 프로그램 실행은 초기(initial) `main` 함수의 호출로 시작한다. `main`에서 `return 표현식;`을 실행하면 표현식의 값이 `main`의 반환 값이 된다.

**[C 표준]** 초기 `main`에서 반환하는 것은 `exit` 함수에 같은 값을 인수로 전달해 호출하는 것과 동등하다. 따라서 다음 두 형태는 종료 의미에서 동등하다.

```c
return 0;
```

```c
exit(0);
```

두 번째 형태에는 `exit`의 선언을 위한 `<stdlib.h>`가 필요하지만, 첫 번째 형태에는 필요 없다.

값 `0`은 성공적인 종료(successful termination)를 나타낸다. 성공 여부는 프로그램이 출력한 내용과 별도다. 아무것도 출력하지 않아도 성공 종료할 수 있고, 출력했어도 다른 값으로 종료할 수 있다.

**[C 표준]** C99 이후에는 초기 `main`의 마지막 `}`에 도달하는 것이 `return 0;`을 실행하는 것과 동등하다. 그러나 학습 초기에는 종료 의도를 명시하는 `return 0;`을 쓰면 코드 읽기가 쉽다.

호스트가 실제로 전달받는 표현과 셸이 관찰 가능한 상태 값은 구현과 환경에 따라 달라질 수 있다. Linux 셸에서 흔히 `$?`로 보이는 값은 유용한 관찰이지만, C의 `int` 값이 운영체제에 정확히 같은 바이트들로 직접 전달된다는 뜻은 아니다.

## 4. 문법

```c
return 0;
```

- `return` 뒤의 `0`은 정수 표현식이다.
- 세미콜론 `;`은 `return` 문을 끝낸다.
- `main`의 반환형이 `int`이므로 반환 표현식은 `int`로 변환될 수 있어야 한다.
- 호스트 환경의 초기 `main`에서는 `return 값;`이 프로그램 종료와 연결된다. 다른 일반 함수의 `return`은 호출한 함수로 제어를 돌려줄 뿐이다.

상태를 관찰하는 GCC/Linux 셸 명령은 다음과 같다.

```sh
./return_zero
printf 'status=%s\n' "$?"
```

`$?`는 **바로 앞 명령**의 상태다. 다른 명령을 먼저 실행하면 그 명령의 상태로 바뀐다.

## 5. 최소 코드 예제

`return_zero.c`의 전체 내용이다.

```c
int main(void)
{
    return 0;
}
```

이 프로그램은 화면에 출력하지 않는다. 정상적인 호스트 실행에서는 성공 종료를 나타낸다.

## 6. 코드 해석

| 줄 | 해석 |
|---|---|
| 1 | 인수를 받지 않고 `int`를 반환하는 초기 `main`을 정의한다. |
| 2 | 함수 본문을 시작한다. |
| 3 | 정수 표현식 `0`을 평가하여 `main`의 반환 값으로 만든다. 초기 `main`이므로 `exit(0)`과 동등한 종료 의미를 가진다. |
| 4 | 함수 본문을 끝낸다. |

이 예제는 표준 출력 함수를 호출하지 않으므로 출력이 없다는 사실은 오류 증거가 아니다. 종료 상태를 확인하려면 실행 직후 셸의 상태를 읽는다.

## 7. 내부 동작

**언어 관점:** **[C 표준]** `return 표현식;`은 표현식을 평가하고 함수 호출을 끝낸다. 초기 `main`에서는 그 반환이 `exit` 호출과 동등한 의미를 가지므로, 등록된 종료 처리와 스트림 정리 같은 `exit`의 의미가 적용된다.

**시작 코드 관점:** **[GCC/Linux 구현]** 일반적인 실행 파일은 `main`의 첫 C 문에서 CPU가 곧바로 시작하지 않는다. 시작 코드와 런타임 준비가 먼저 실행되고, 이후 초기 `main`이 호출된다. `main`의 반환 값은 런타임과 운영체제 경계를 거쳐 셸이 관찰할 수 있는 상태로 표현될 수 있다.

**경계 관점:** C 표준은 성공 종료의 의미를 규정하지만, 특정 운영체제의 종료 코드 폭, 셸 변수 이름, 프로세스 제어 블록 형식은 규정하지 않는다. 따라서 Linux에서 `0`이 보였다는 관찰과 호스트 내부 전달 형식을 같은 주장으로 섞지 않는다.

## 8. 자주 하는 실수

- **`return 0;`이 단지 프로그램을 멈추는 문장이라고 말한다.** 초기 `main`에서는 반환 값 0으로 성공 종료를 나타낸다.
- **운영체제가 C의 정수 바이트를 그대로 받는다고 단정한다.** 호스트 표현과 셸 관찰 방식은 구현·환경별이다.
- **출력이 없으면 실패라고 생각한다.** 출력과 종료 상태는 별개다.
- **일반 함수의 `return 0;`도 프로그램 전체를 끝낸다고 생각한다.** 일반 함수는 호출자에게 제어와 값을 돌려준다.
- **`$?`를 늦게 읽는다.** 다른 셸 명령 뒤에는 직전 상태가 바뀐다.
- **C99 이후 생략 가능하므로 `return 0;`이 의미 없다고 생각한다.** 생략 가능성과 명시적 의도 표시는 다른 문제다.

## 9. 필수 실습

### 성공 종료 상태 관찰

- **목적:** 프로그램 출력과 종료 상태를 독립적으로 확인한다.
- **해야 할 일:** [실습 안내](../../exercises/01-program-structure/1-6/README.md)에 따라 `return_zero.c`를 직접 작성한다. 빌드한 뒤 실행하고, 즉시 `$?`를 기록한다. 이어서 출력이 없지만 성공 종료한 이유를 한 문장으로 설명한다.
- **사용할 개념:** 초기 `main`, `return 0;`, 성공 종료, 셸의 직전 명령 상태.
- **예상 관찰 결과:** 일반적인 GCC/Linux 셸에서는 프로그램이 출력 없이 끝나고 직후 상태가 `0`으로 보인다. 이는 해당 환경의 관찰이다.
- **확인 포인트:** 상태를 실행 직후 읽었는가? 출력 결과와 종료 상태를 구분했는가? 운영체제가 `int`를 그대로 받는다고 기록하지 않았는가?

## 10. 추가 실습

- ★ **명시적 반환과 끝 도달 비교:** 별도 파일에서 C99 이후 초기 `main`의 끝에 도달하는 형태를 작성하고, `return 0;` 형태와 관찰 결과를 비교한다.
- ★ **직전 상태의 변화:** 프로그램 실행 직후 `$?`를 기록한 뒤 `printf`를 실행하고 다시 `$?`를 확인한다. 두 번째 값이 무엇의 상태인지 설명한다.
- ★★ **비성공 값 관찰:** 별도 연습 파일에서 0이 아닌 값을 반환하고 셸에서 보이는 상태를 기록한다. 이 관찰을 모든 호스트의 동일한 표현이라고 일반화하지 않는다.

## 11. 확인 문제

1. 초기 `main`의 `return 0;`은 무엇을 나타내는가?
2. 초기 `main`에서 `return value;`은 어떤 함수 호출과 동등한가?
3. C99 이후 초기 `main`의 마지막 `}`에 도달하면 어떤 의미를 갖는가?
4. 프로그램에 출력이 없으면 실패인가?
5. `$?`는 언제 읽어야 실행한 프로그램의 상태인가?

<details>
<summary>정답과 해설 펼치기</summary>

1. 값 0으로 성공 종료를 나타낸다.
2. `exit(value)` 호출과 동등하다.
3. `return 0;`을 실행한 것과 동등하다.
4. 아니다. 출력과 성공·실패 종료 상태는 별개의 관찰이다.
5. 프로그램 실행 직후, 다른 셸 명령을 실행하기 전에 읽어야 한다.

</details>

## 12. 핵심 정리

- 초기 `main`의 `return 표현식;`은 표현식의 값을 반환한다.
- 초기 `main`에서 그 반환은 `exit(값)` 호출과 동등하다.
- `return 0;`은 성공 종료를 나타낸다.
- C99 이후 초기 `main` 끝에 도달하는 것은 `return 0;`과 동등하다.
- 호스트의 실제 종료 상태 표현과 셸의 관찰 방식은 구현·환경별이다.
