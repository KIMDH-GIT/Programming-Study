# 2-1. 변수 선언·초기화와 이름 규칙

기준은 C17의 호스트 환경이다. 이번 Step은 정수 값을 이름으로 다루는 첫 단계다. 이름, 객체, 값, 저장 공간을 구분하고 선언·초기화·대입을 직접 관찰한다.

## 1. 학습 목표

- `int score = 10;`에서 자료형, 식별자, 초기값을 찾는다.
- 선언, 정의, 초기화, 대입의 역할을 구별한다.
- 객체의 현재 값과 그 객체를 가리키는 이름을 구별한다.
- 읽기 전에 값을 정하고, 예약 이름을 피한 식별자를 사용한다.
- 변수마다 반드시 스택 공간이 생긴다고 단정하지 않는다.

## 2. 선수 지식

[Part 1의 출력](../01-program-structure/1-4-printf-multiline-output.md)에서 배운 `<stdio.h>`, `int main(void)`, `printf`, `\n`, 세미콜론을 사용한다. 빌드는 소스를 실행 파일로 만드는 작업이고 실행은 별도 작업이다.

Linux 셸과 GCC를 사용한다. `%d`와 출력 인수의 대응은 여기서 필요한 만큼 처음 설명하며 입력, 조건 분기, 반복은 필요하지 않다.

## 3. 핵심 개념

### 이름은 객체도 값도 아니다

`int score = 10;`을 `main` 본문에 쓴 상황을 기준으로 읽는다.

| 용어 | 의미 | 예제에서의 역할 |
|---|---|---|
| 식별자(identifier) | 소스에서 대상을 식별하는 이름 | `score` |
| 객체(object) | C 추상 기계에서 값을 나타낼 수 있는 데이터 저장 영역 | `score`로 지칭하는 정수 객체 |
| 자료형(type) | 표현 가능한 값과 허용되는 연산·해석을 정하는 분류 | `int` |
| 값(value) | 객체가 현재 나타내는 데이터 | 초기에는 정수 10 |
| 저장 공간(storage) | 객체의 표현을 담는 공간 | 크기·정렬·수명 등이 관련되며 이름 자체와 다름 |
| 선언(declaration) | 식별자의 의미와 자료형 같은 속성을 알리는 구문 | `int score = 10;` 전체 |
| 정의(definition) | 객체의 경우 그 객체의 저장 공간을 마련하는 선언 | 이 블록의 `score` 선언은 정의이기도 함 |
| 초기화(initialization) | 객체의 처음 값을 지정하는 일 | 선언의 `= 10` |
| 대입(assignment) | 이미 있는 수정 가능한 객체에 값을 저장하는 연산 | 이후의 `score = 20;` |

이 Step에서 **변수**는 이름으로 사용하는, 값을 바꿀 수 있는 객체를 뜻한다. 모든 식별자가 변수 이름인 것은 아니다. `main`과 `printf`도 식별자지만 여기서는 함수 이름이다. 객체에 언제나 소스상의 이름이 있어야 하는 것도 아니다. 이름 없는 객체는 뒤에서 다룬다.

**[C 표준]** 선언이 모두 객체 정의인 것은 아니다. 예를 들어 함수 선언은 정수 객체를 만드는 선언이 아니다. 지금 작성하는 `main` 내부의 `int score;`와 `int score = 10;`은 모두 객체의 선언이자 정의다. 선언과 정의의 전체 구분은 여러 파일을 다루는 Part 24에서 확장한다.

### 초기화와 대입은 같은 기호를 써도 다르다

- `int score = 10;`: 새 객체의 선언·정의와 초기화다.
- `score = 20;`: 기존 객체에 20을 저장하는 대입식 문장이다. 새 객체를 만들거나 자료형을 바꾸지 않는다.
- `printf("%d\n", score);`: 객체의 현재 값을 읽어 출력에 사용한다. 이름 자체를 출력하는 것이 아니다.

`%d`는 `int` 값을 부호 있는 10진수로 출력하는 변환 지정자다. 서식 문자열 다음에 출력할 값을 인수로 전달한다. `printf("score\n");`는 글자 `score`만 출력한다. 이번에는 `%d` 하나에 `int` 인수 하나를 정확히 대응시킨다.

### 값이 정해지기 전에 읽지 않는다

**[C 표준]** 여기서 사용하는 초기화 없는 자동 저장 기간의 지역 객체 `int score;`는 값이 0으로 정해지지 않는다. 값은 불확정(indeterminate) 상태다. 그 값을 출력해서 확인하는 것은 안전한 실험이 아니며 정의되지 않은 동작으로 이어질 수 있다. 일정한 쓰레기값이나 무작위 숫자가 나온다는 보장도 없다.

`int score;` 뒤에 값을 읽지 않고 `score = 10;`부터 실행하는 것은 가능하다. 이때 처음 저장한 값이라도 문법상 **대입**이지 선언의 **초기화**가 아니다. 처음부터 값을 알면 선언과 함께 초기화하는 습관을 권한다. 다른 저장 기간의 객체에 적용되는 기본 초기화 규칙을 모든 지역 변수에 일반화하지 않는다.

## 4. 문법

다음은 함수 본문에 놓는 구문 조각이다.

```c
int score = 10;
score = 20;
int count;
count = 3;
```

`int`는 자료형 키워드, `score`와 `count`는 식별자, `10`, `20`, `3`은 정수 상수다. 각각의 선언과 문장 끝에 세미콜론을 쓴다. 이 자료에서는 가독성을 위해 한 선언에 변수 하나를 쓴다.

### 식별자 규칙과 이름 선택

초보 단계에서는 영문자, 숫자, 밑줄만 사용한다.

- 첫 글자는 영문자 또는 밑줄이어야 하고 숫자로 시작할 수 없다.
- 뒤에는 영문자, 숫자, 밑줄을 쓸 수 있다. 공백과 `-`는 이름에 넣지 않는다.
- 대소문자를 구분한다. `score`와 `Score`는 다른 이름이다.
- `int`, `return` 같은 키워드는 변수 이름으로 사용할 수 없다.
- 같은 블록에서 같은 이름의 지역 객체를 다시 정의하지 않는다. 값을 바꿀 때는 자료형을 반복하지 말고 대입한다.
- 선언한 이름은 그 이름이 보이는 범위에서 사용한다. 이번에는 모두 `main`의 같은 블록에서 선언 뒤에 사용한다.

**[C 표준]** 실제 식별자 문법에는 일부 비ASCII 문자 지원도 있지만 허용 범위와 이식성을 고려해 이 Step의 이름은 ASCII로 제한한다. 밑줄로 시작한다고 모두 자유롭게 쓸 수 있는 것은 아니다. `__`로 시작하거나 밑줄 다음이 대문자인 이름은 모든 용도로 예약되며, 나머지 밑줄 시작 이름도 파일 범위 등에서 예약 규칙이 있다. 이번에는 **밑줄로 시작하는 이름을 아예 선택하지 않는다.**

| 후보 | 판단 |
|---|---|
| `student_count`, `score2` | 사용할 수 있고 뜻도 표현할 수 있음 |
| `2score` | 숫자로 시작하므로 불가 |
| `student-count` | 하나의 식별자가 아님 |
| `return` | 키워드이므로 불가 |
| `__score`, `_Score` | 문법 모양과 별개로 구현에 예약된 이름 |
| `printf` | 표준 라이브러리 이름과 충돌하므로 사용자 변수 이름으로 피함 |

이름에 단위를 담는 `elapsed_seconds`는 `x`보다 의미를 전달하기 쉽다. 이름의 의미가 자료형의 범위를 늘려 주지는 않는다.

## 5. 최소 코드 예제

`variables.c`에 저장한다. 출력에 필요한 값은 모두 먼저 정한다.

```c
#include <stdio.h>

int main(void)
{
    int score = 10;
    int saved_score = score;

    printf("score=%d\n", score);
    score = 20;
    printf("score=%d\n", score);
    printf("saved_score=%d\n", saved_score);
    return 0;
}
```

```sh
gcc -std=c17 -Wall -Wextra -Wpedantic variables.c -o variables && ./variables
```

정상 표준 출력 환경에서 예상 결과는 다음과 같다.

```text
score=10
score=20
saved_score=10
```

## 6. 코드 해석

| 코드 | 해석 |
|---|---|
| `#include <stdio.h>` | `printf` 선언을 제공받는다. |
| `int main(void)` | 매개변수 없이 시작해 `int`를 반환하는 함수다. |
| `int score = 10;` | `int` 객체를 정의하고 10으로 초기화한다. |
| `int saved_score = score;` | `score`의 현재 값 10을 읽어 별개의 객체를 초기화한다. |
| 첫 `printf` | 이 시점의 `score` 값 10을 출력한다. |
| `score = 20;` | 같은 `score` 객체에 새 값 20을 저장한다. |
| 뒤의 두 `printf` | 바뀐 값 20과 복사해 둔 값 10을 각각 출력한다. |
| `return 0;` | 초기 `main` 호출을 정상 종료한다. 화면에 0을 출력하지 않는다. |

`int saved_score = score;`는 두 이름을 같은 객체에 붙이는 동작이 아니다. 정수 **값을 복사**했으므로 나중에 `score`를 바꿔도 `saved_score`가 자동으로 따라 바뀌지 않는다.

## 7. 내부 동작

1. **[C 표준·번역]** 선언을 통해 이름과 자료형이 연결된다. 컴파일러는 선언되지 않은 이름 사용과 문법·제약 위반을 진단한다. 모든 잘못된 실행을 미리 찾아준다는 뜻은 아니다.
2. **[C 표준·객체]** 예제의 지역 객체는 자동 저장 기간을 가진다. 이번 블록에 들어올 때 수명이 시작되고 블록 실행이 끝나면 수명이 끝난다. 초기화 구문에 도달하면 지정된 초기값을 저장한다. 이름이 보이는 범위와 객체의 수명은 서로 관련되지만 다른 개념이다.
3. **[C 표준·값]** 대입은 객체의 저장된 값을 바꾸며, 읽기는 현재 값을 계산에 제공한다. 이름을 바꾸는 동작도 저장 공간 크기를 바꾸는 동작도 아니다.
4. **[구현·컴파일러/CPU]** 실제 저장은 스택 슬롯, CPU 레지스터 등을 이용할 수 있고 최적화로 별도 저장 공간 자체가 없어질 수도 있다. 예제의 출력값을 미리 계산해 전달해도 허용되는 관찰 가능한 동작이 유지되면 된다. C 표준은 모든 변수를 스택에 배치하라고 요구하지 않는다.
5. **[GNU/Linux 구현·OS]** OS는 프로세스의 실행 환경과 가상 메모리 등을 관리한다. 소스의 `score`라는 이름을 보고 대입을 수행하는 것은 아니다. CPU는 컴파일된 기계 명령을 실행하고 출력은 C 라이브러리와 OS를 통해 전달된다.

## 8. 자주 하는 실수

- 선언만 하면 모든 변수가 0이라고 생각한다. 이번 자동 지역 객체는 먼저 초기화하거나 대입해야 한다.
- `score = 20;` 앞에 다시 `int`를 붙인다. 같은 블록에서 재정의하는 대신 대입한다.
- 초기화의 `=`를 실행 중 대입 연산자와 문법적으로 동일하다고 설명한다.
- `Score`를 써 놓고 `score`를 읽는다. 대소문자가 다른 별개 이름이다.
- `%d`에 대응하는 인수를 빠뜨린다. 경고를 확인하고 인수를 맞춘다.
- `saved_score`가 원본의 별명이라고 생각한다. 예제는 값을 복사한다.
- 변수가 들어 있는 메모리에 소스 이름도 반드시 함께 저장된다고 생각한다. 디버그 정보와 실행에 필요한 값의 표현은 별개다.
- 빌드 실패 뒤 이전 실행 파일을 실행한다. 성공한 빌드만 `&&`로 실행에 연결한다.

- **사용할 개념:** 객체, `int`, 식별자, 초기화, 값 복사, 대입, `%d`, `\n`.

## 11. 확인 문제

1. **용어 대응:** `int attempts = 3;`에서 식별자, 자료형, 초기값을 각각 고르라. 이 줄은 선언인가, 정의인가?
2. **참/거짓:** `int attempts;`를 `main` 안에 쓰면 바로 출력해도 반드시 0이다. 이유도 쓰라.
3. **출력 예측:** `int first = 4; int second = first; first = 8;` 뒤 두 값을 순서대로 출력하면 무엇인가?
4. **이름 분류:** `item_count`, `3items`, `return`, `__items` 중 이번 학습자의 변수 이름으로 적절한 것은 무엇인가?
5. **오류 수정:** 같은 블록의 `int score = 1; int score = 2;`를 객체 하나의 값 변경이라는 의도에 맞게 고치라.
6. **서술:** “변수 이름 하나는 항상 스택 메모리 칸 하나다”가 부정확한 이유를 설명하라.

4. `item_count`다. `3items`는 숫자로 시작하고 `return`은 키워드다. `__items`는 구현에 예약된 이름이다.
5. 두 번째 구문을 `score = 2;`로 바꾼다. 기존 객체에 대입하는 문장이다.
6. 식별자는 소스의 이름이고 객체는 C의 저장 영역 개념이다. 실제 구현은 레지스터를 쓰거나 저장 자체를 최적화할 수 있으며 C는 스택 배치를 의무화하지 않는다.

</details>

## 12. 핵심 정리

식별자는 이름, 객체는 값을 나타내는 저장 영역, 자료형은 값과 연산의 규칙, 값은 현재 데이터다. 이번 지역 변수 선언은 정의이기도 하다. 초기화는 처음 값을 지정하고 대입은 이미 있는 객체에 값을 저장한다. 읽기 전에 값을 정하고, 뜻이 분명한 비예약 이름을 고른다. C의 객체 모형과 실제 스택·레지스터 배치를 구분한다.
