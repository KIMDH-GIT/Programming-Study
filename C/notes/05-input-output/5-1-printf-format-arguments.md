# 5-1. `printf` 서식 문자열과 인자 대응

`printf`는 서식 문자열을 읽으며 변환 지시마다 뒤의 인자 하나를 소비한다. 출력 모양뿐 아니라 인자의 실제 형까지 맞추는 것이 핵심이다.

## 1. 학습 목표

- 서식 문자열, 변환 지정, 인자를 구별한다.
- 변환 지정과 인자가 순서대로 대응함을 설명한다.
- `printf` 반환값의 의미를 말한다.

## 2. 선수 지식

문자열 리터럴, 함수 호출, 인자, 기본 정수·실수형을 사용한다. 가변 인수 함수의 내부 구현은 이번 범위가 아니다.

## 3. 핵심 개념

`printf("age=%d score=%.1f\n", age, score);`에는 서식 문자열 하나와 출력할 인자 둘이 있다. `%d`는 첫 번째 추가 인자, `%.1f`는 두 번째 추가 인자에 대응한다. 일반 문자는 그대로 출력되고 `%%`는 인자를 소비하지 않고 `%` 하나를 출력한다.

**[C17 표준]** 변환 지정이 요구하는 형과 실제 인자형이 맞지 않으면 동작이 정의되지 않을 수 있다. 인자 개수가 부족해도 안전하지 않다.

## 4. 문법

```c
int written = printf("name=%s age=%d\n", "Kim", 20);
```

반환값은 성공하면 출력한 문자 수, 출력 또는 인코딩 오류가 생기면 음수다.

## 5. 최소 코드 예제

```c
#include <stdio.h>

int main(void)
{
    int age = 20;
    int written = printf("age=%d%%\n", age);

    printf("written=%d\n", written);
    return 0;
}
```

## 6. 코드 해석

1. `%d`는 `age`를 10진 signed 정수로 출력한다.
2. `%%`는 추가 인자를 소비하지 않는다.
3. 첫 호출의 반환값에는 줄바꿈 문자도 포함된다.
4. 두 번째 호출은 첫 호출이 출력한 문자 수를 보여 준다.

## 7. 내부 동작

**[라이브러리 관점]** `printf`는 서식 문자열을 왼쪽부터 해석하고 표준 출력 스트림에 문자를 쓴다.

**[가변 인수 관점]** 추가 인자의 형 정보가 따로 전달되지 않으므로 서식 문자열이 올바른 해석 계약이 된다.

## 8. 자주 하는 실수

- 변환 지정 수와 인자 수를 다르게 쓴다.
- 인자의 순서를 바꾼다.
- `%` 문자를 출력하면서 `%%`를 쓰지 않는다.
- 성공 시 반환값을 출력한 “항목 수”라고 생각한다.

## 9. 필수 실습

이름, 나이, 진도율을 한 줄에 출력하고 `printf` 반환값을 다음 줄에 출력한다. 절차는 [실습 README](../../exercises/05-input-output/5-1/README.md)를 따른다.

## 10. 추가 실습

- ★ **기초:** 일반 문자만 출력한 호출의 반환값을 예측한다.
- ★★ **응용:** `%%` 두 개가 반환값에 미치는 영향을 확인한다.
- ★★★ **도전:** 인자 순서를 바꾼 잘못된 코드를 실행하지 말고 문제를 설명한다.

## 11. 확인 문제

1. 서식 문자열과 추가 인자는 어떤 순서로 대응하는가?
2. `%%`는 인자를 소비하는가?
3. 성공한 `printf`의 반환값은 무엇인가?
4. 변환 지정과 인자형이 맞지 않으면 어떤 문제가 생길 수 있는가?

## 12. 핵심 정리

`printf` 호출은 서식 문자열이 요구하는 개수·순서·형의 인자를 정확히 제공해야 한다. 반환값은 성공 시 출력 문자 수다.
