# 5-5. `%p`, `(void *)`와 주소 출력 예고

`%p`는 포인터 값을 구현이 정한 문자 형태로 출력한다. 이번 Step은 변수 주소를 관찰하는 문법만 예고하며 포인터 연산이나 역참조는 다루지 않는다.

## 1. 학습 목표

- 주소 연산자 `&`가 객체의 주소를 만든다고 설명한다.
- `%p`가 `void *` 인자를 요구함을 말한다.
- 출력 주소의 구체적 형태가 구현 정의임을 설명한다.

## 2. 선수 지식

객체와 변수, 함수 인자, Step 5-1의 형식 대응을 사용한다. 포인터의 본격적인 학습은 Part 14에서 한다.

## 3. 핵심 개념

`&value`는 `value` 객체를 가리키는 포인터다. `%p`에 전달할 때 `(void *)&value`처럼 `void *`로 변환해 요구형을 명시한다. **[C17 표준]** 출력 문자의 형태는 구현 정의다. 흔히 16진 주소처럼 보이지만 표준이 특정 접두사·자리 수를 고정하지 않는다.

## 4. 문법

```c
printf("%p\n", (void *)&value);
```

## 5. 최소 코드 예제

```c
#include <stdio.h>

int main(void)
{
    int value = 42;

    printf("value=%d\n", value);
    printf("address=%p\n", (void *)&value);
    return 0;
}
```

## 6. 코드 해석

1. `value`는 정수 객체다.
2. `&value`는 그 객체의 주소를 만든다.
3. `(void *)`는 `%p`가 요구하는 포인터형으로 변환한다.
4. 출력 주소는 한 실행의 관찰값이다.

## 7. 내부 동작

실행 환경은 객체가 놓일 저장 위치를 정하지만 컴파일러 최적화와 OS의 주소 공간 배치가 관찰값에 영향을 줄 수 있다. 주소값을 실행 간에 고정이라고 가정하지 않는다.

## 8. 자주 하는 실수

- `%p`에 정수값 자체를 넘긴다.
- 객체 포인터를 필요한 변환 없이 임의 서식으로 출력한다.
- 주소 출력 형태를 모든 구현에서 같은 16진수라고 단정한다.
- 출력된 주소를 역참조하거나 산술하려 한다.

## 9. 필수 실습

## 10. 추가 실습

- ★ **기초:** 한 객체 주소를 두 번 출력한다.
- ★★ **응용:** 두 객체 주소가 다를 수 있음을 관찰한다.
- ★★★ **도전:** 실행마다 주소가 달라질 수 있는 이유를 조사한다.

## 11. 확인 문제

1. `&value`는 무엇을 만드는가?
2. `%p`가 요구하는 인자형은 무엇인가?
3. 주소의 출력 형태는 C17이 고정하는가?
4. 이번 Step에서 역참조를 다루는가?

## 12. 핵심 정리

객체 주소는 `&`로 얻고 `%p`에는 `(void *)`로 변환해 전달한다. 구체적인 출력 표현은 구현 정의이며 포인터의 사용 규칙은 뒤 Part로 미룬다.
