# 5-7. `scanf` 구조와 변수 주소

`scanf`는 입력 문자를 해석해 호출자가 제공한 객체에 값을 저장한다. 값을 바꾸려면 변수의 값이 아니라 저장 위치인 주소를 전달해야 한다.

## 1. 학습 목표

- `scanf`의 서식 문자열과 저장 인자를 구별한다.
- 스칼라 변수 앞에 `&`가 필요한 이유를 설명한다.
- 입력 성공 개수를 반환값으로 확인한다.

## 2. 선수 지식

Step 5-5의 주소 연산자 예고와 정수 변수 선언을 사용한다. 포인터 일반 규칙은 Part 14에서 다룬다.

## 3. 핵심 개념

`scanf("%d", &value)`에서 `%d`는 입력 문자를 signed 10진 정수로 해석하고 `&value`가 가리키는 `int` 객체에 저장한다. 반환값은 성공적으로 대입한 항목 수이며, 첫 변환 전에 입력 끝이 오면 `EOF`일 수 있다.

서식 문자열의 공백과 일반 문자는 입력 소비 규칙을 가진다. 프롬프트 출력과 입력 호출은 별개다.

## 4. 문법

```c
int matched = scanf("%d", &value);
```

## 5. 최소 코드 예제

```c
#include <stdio.h>

int main(void)
{
    int value = 0;
    int matched;

    printf("integer: ");
    matched = scanf("%d", &value);
    printf("matched=%d value=%d\n", matched, value);
    return 0;
}
```

## 6. 코드 해석

1. `value`를 먼저 0으로 초기화한다.
2. `&value`는 저장 대상의 주소다.
3. 올바른 정수 하나를 읽으면 `matched`는 1이다.
4. 실패하면 초기값이 그대로일 수 있으며 반환값이 결과를 알려 준다.

## 7. 내부 동작

표준 입력 스트림의 문자를 서식에 따라 소비하고 변환한다. 성공한 변환 뒤에만 대응 객체에 대입한다. 터미널의 줄 단위 동작은 C 언어가 아니라 실행 환경의 입력 장치 특성도 포함한다.

## 8. 자주 하는 실수

- `scanf("%d", value)`처럼 주소 연산자를 빼먹는다.
- 반환값을 입력값 자체라고 생각한다.
- 프롬프트 뒤 줄바꿈이 없을 때 항상 즉시 보인다고 단정한다.
- 실패한 입력 뒤 객체가 새 값으로 바뀌었다고 가정한다.

## 9. 필수 실습

정수 하나를 입력하고 반환값과 저장값을 함께 출력한다. [실습 README](../../exercises/05-input-output/5-7/README.md)를 따른다.

## 10. 추가 실습

- ★ **기초:** 양수와 음수를 입력한다.
- ★★ **응용:** 숫자가 아닌 입력의 반환값을 관찰한다.
- ★★★ **도전:** EOF 입력의 반환값을 기록한다.

## 11. 확인 문제

1. 스칼라 변수에 `&`가 필요한 이유는 무엇인가?
2. 성공적으로 정수 하나를 대입하면 무엇을 반환하는가?
3. 첫 변환 전에 입력 끝이면 어떤 값을 반환할 수 있는가?
4. 입력 실패 시 반환값 확인이 필요한 이유는 무엇인가?

## 12. 핵심 정리

`scanf`는 저장 대상 객체의 주소를 받아 입력값을 대입한다. 반환값은 성공한 대입 수이므로 입력값과 별개로 확인해야 한다.
