# 29-10. GCD
## 1. 학습 목표
- Euclidean algorithm의 invariant와 종료를 설명한다.
- zero input을 application contract로 정의한다.
- modulo 연산을 unsigned 범위에서 안전하게 사용한다.
## 2. 선수 지식
Part 7의 `%`, Part 9의 loop, 29-1의 contract를 안다.
## 3. 핵심 개념
**[Algorithm]** `a = bq + r`이면 `gcd(a, b) == gcd(b, r)`이다. 따라서 나머지가 0이 될 때까지 `(a, b)`를 `(b, a % b)`로 바꾼다.

이 Step의 contract:

```text
gcd(a, 0) = a
gcd(0, b) = b
gcd(0, 0) = 0  /* 이 프로그램의 convention */
```

마지막 줄은 모든 수학 교재의 유일한 정의가 아니라 application contract다.
## 4. 문법
```c
while (b != 0U) {
    unsigned int remainder = a % b;
    a = b;
    b = remainder;
}
```

`b != 0`일 때만 `% b`를 평가하므로 division by zero를 만들지 않는다.
## 5. 최소 코드 예제
```c
#include <stdio.h>

static unsigned int gcd(unsigned int a, unsigned int b)
{
    while (b != 0U) {
        unsigned int remainder = a % b;
        a = b;
        b = remainder;
    }
    return a;
}

int main(void)
{
    printf("%u\n", gcd(48U, 18U));
    printf("%u\n", gcd(0U, 7U));
    printf("%u\n", gcd(0U, 0U));
    return 0;
}
```

```sh
gcc -std=c17 -Wall -Wextra -Wpedantic -Werror main.c -o gcd
./gcd
```
## 6. 코드 해석
`(48, 18)`은 `(18, 12)`, `(12, 6)`, `(6, 0)`으로 진행해 6을 반환한다. zero boundary outputs은 7과 0이다.
## 7. 내부 동작
**[Algorithm]** common divisor 집합이 각 iteration에서 유지된다. nonzero `b`는 다음 나머지로 바뀌며 `0 <= remainder < b`라서 종료를 향해 진행한다. 두 값이 nonzero일 때 time은 `O(log min(a, b))`, auxiliary space는 `O(1)`이다.

**[C17]** unsigned arithmetic과 `%` 규칙을 사용한다. signed minimum의 absolute value 문제를 피하려고 이 예제는 nonnegative input을 `unsigned int`로 받는다.

**[Compiler / CPU]** modulo가 어떤 instruction sequence가 되는지는 target과 compiler의 영역이다.
## 8. 자주 하는 실수
- `b == 0`을 확인하기 전에 `a % b`를 계산한다.
- negative input 처리 contract를 생략한다.
- `gcd(0, 0)` convention을 C17이 정한다고 말한다.
- iteration 수를 실제 CPU cycle과 동일시한다.
